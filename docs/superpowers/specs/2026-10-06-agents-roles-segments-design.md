## 1 范围

做：
- 后台三类登录身份：最高权限者 / 管理员 / 代理，统一登录同一管理后台，按角色显示菜单与数据。
- 代理资料：名称（全局唯一，改名后旧名保留一年）、身份等级（省级/市级/VIP，手动设置）、层级关系（上级代理，手动维护）、资格状态（激活/暂停/取消，含变更人、时间、原因）。
- 账号编号段：分配（管理员→代理）、划拨（高级代理→其关联下级代理，不可撤回）、回收（代理资格取消后由管理员回收未激活编号并解除原上级关系）；总配额 / 已用 / 剩余。
- 代理在本人编号段内激活账号（复用 A 的激活逻辑：预置 123456）；首次激活时记录直接/间接/次间接上级（仅展示直接上级）。
- 权限授权：最高权限者把「代理改名」等授权项授予指定管理员，可撤销；被授权者不得转授。
- 所有操作写审计日志（A 已建表，保留三年）。

不做：积分与积分划转（C）、通知渠道（仍只记日志）。

## 3 数据模型（草案）

- `admins` 增加 `role TEXT NOT NULL DEFAULT 'admin'`（`super|admin|agent`）、`status`（`active|disabled`）。存量管理员迁移为 `super`（见 Q4）。
- `agents`：`admin_id`（登录身份）、`name UNIQUE`、`level`（province/city/vip）、`parent_agent_id`、`tier`（senior/junior，见 Q5）、`status`（active/paused/cancelled）、`status_by`、`status_at`、`status_reason`、`created_at`。
- `agent_name_history`：`name`、`agent_id`、`released_at`、`reserved_until = released_at + 365天`；新名称与在用名称或保留期内旧名称冲突 → 「该名称已被使用」。
- `segments`：`id`、`prefix`、`start_no`、`end_no`、`owner_agent_id`、`source_segment_id`（划拨来源）、`created_by`、`created_at`、`status`（active/recycled）。划拨 = 从父段切出子区间生成新段，父段对应区间标记为已划出（不可撤回）。
- `users` 增加 `agent_id`（直接上级）、`agent_chain_json`（首次激活时记录的直接/间接/次间接上级，仅用于判定与查询）。
- `admin_grants`：`admin_id`、`grant`（`agent.rename` 等）、`scope_json`、`granted_by`、`granted_at`、`revoked_at`。

## 4 编号状态（第5节五态）

管理列表显示的「编号状态」由数据推导，不另存：
- 已分配：在某代理段内、尚未建档/未交给用户（见 Q2）
- 待激活：已建档但 `first_activated_at IS NULL`
- 已激活：已激活且余额 > 0（C 之前视为已激活）
- 已欠费：已激活且余额 = 0（C 实现后生效）
- 待回收：所属代理资格已取消且未激活

使用控制（正常/暂停/封禁）为独立字段（A 已有 `status`）。

## 5 待确认问题

- **Q1 编号格式**：账号编号是 7 位（登录框要求 7 位）。编号是「字母前缀 + 数字」（如 `A000001`）还是纯数字？编号段如何表示（前缀 + 起止数字）？线上已有账号的编号规律是什么？
- **Q2 何时建档**：分配编号段时是否立即为段内每个编号建「待激活」账号（便于列表显示状态），还是代理把编号交给用户/激活时才建档？「已分配」与「待激活」的区别是否就是「是否已建档/交给用户」？
- **Q3 代理与软件账号的关系**：代理是否同时也是一个能登录客户端的软件账号（有积分、能用软件），还是只登录后台的独立身份？C 中「高级代理从自身余额向下级转积分」意味着代理有积分余额——代理积分和软件账号积分是否同一个余额？
- **Q4 最高权限者**：现有后台管理员（`manage.py admin-set` 创建）是否全部视为「最高权限者」？最高权限者是否只能有一个？
- **Q5 高级/低级**：文档说高级/低级关系与省级/市级/VIP 不固定映射、由最高权限者手动维护。是否可以简化为「上级代理就是高级，下级就是低级」（即只维护上下级关系，不单独存 tier）？
- **Q6 管理员「按权限设置代理」**：第3节写管理员「按权限设置代理、划拨账号段」，第8节 C-17-04 写「最高权限者可手动设置身份」。管理员能否新建代理、设置等级与层级，还是只有最高权限者能？
- **Q7 代理名称保留期**：改名后旧名进入「非正常户保留期一年」，代理被取消资格时其名称是否同样保留一年？
