# 排列三过滤引擎 — 样板说明

从原 Windows 版 `arithmetic.node` 逆向出的规格，用 JS 重写。目标：Mac 版不依赖 Windows DLL、也不必依赖服务器 serviceAi。

## 流水线（本样板已跑通前 3 步）
1. **抽规格**：从解包出的前端代码提取排列三条件定义（下表）。✅
2. **JS 实现**：`pl3.js`，按原 app 的 `play[]` 入参格式。✅（和值/跨度/胆码）
3. **自测**：`pl3.test.js`，手算真值验证，7/7 通过。✅
4. **对照真程序**（需你来做）：见下方"校验"。⏳

## 待你确认的语义（歧义点）
- **tolerant 容错**：不确定是"单条件内允许错几位"还是"多条件间允许不满足几条"。
  本样板按后者理解、单条件不受影响。请用真程序设一个带容错的条件对一下。

## 校验方法（闭环最后一步）
在 Windows 原程序里，对排列三设定某个条件（如"和值=10"），把它算出的号码列表导出/截图；
再运行 `node -e "console.log(require('./pl3').filter([{id:'plsr3002',arr:[10]}]).length)"`，
对比两边数量与具体号码。一致即说明该条件还原正确。
